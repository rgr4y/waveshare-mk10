# PictureFont

Dot-matrix glyph images from the vendor ScreenKey app
(`ScreenKeyMacOS.app/Contents/MacOS/image/MK10/PictureFont/点数字/0-9.png`, 128x128, transparent).
`dot-colon.png` (two dots, for clocks) is `image/128x128/PictureFont/点-.png` (64x128), padded to 128x128 with transparency.
Choose icon… lists them below the line-art icons.
