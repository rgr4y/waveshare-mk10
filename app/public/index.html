              Key actions and stats
              
        
        
              When a key is pressed, the device reports its action and Studio runs the ones the Mac handles: Open website (http and https only), Open folder and Open file (scripts and apps are refused there), and Studio's own Run application, Run script and Run Shortcut keys (each program asks once). Keyboard, macro and page keys run on the device either way. Typing text, passwords, sound devices, screenshots and music are not supported yet. While either is on, Studio keeps the MK10's USB serial port open, so the vendor ScreenKey app can't use it.
              
        
        
              Once a second: CPU, GPU and RAM usage, CPU model, disk space, and network speed and totals, for the widgets the current page shows (CPU Usage, GPU Usage, RAM Usage and the other names the vendor app uses). Temperatures are not sent (Apple Silicon sensors need root). The device keeps its own clock and date.
              
      
              

      
              
        
              MCP server
              
        
              Lets Claude (or any MCP client) read and edit the open theme and push it. Listens on 127.0.0.1 only.

              Device fonts
              
        
              The MK10 draws titles and clocks with its own fonts. Studio copies them from the device over ssh (LilAlpine) for the preview; they stay in Studio's data folder.

              Developer
              
        
        
              A separate window that shows every JSON-RPC message Studio sends to the device's KeyboardDevice over USB serial, and each reply. While the window is open, Studio keeps the port open (and retries if it's unplugged), so messages the device sends on its own show too. That locks the port against the vendor app. ssh pushes don't show.
